# Daily English Learning

Public GPT-authored B1 English reading material for the Asset Manager Android learning page.

- One 400–600-word article per Taipei date; mixed learning, life, technology, sport and verified news topics.
- Each paragraph contains ordered English/Traditional Chinese meaning spans. The dictionary covers every English word; optional IPA is provided when verified. The app highlights the corresponding meaning span, not a fabricated word-for-word translation.
- `index.json` records each article SHA-256. `articles/YYYY-MM-DD.json` is immutable after publication. Existing articles stay available for offline reading after download.
- Generation starts at 00:00 Asia/Taipei on the owner's local Codex desktop. Publication follows successful validation; the computer and Codex must be running. There is no exact completion-time guarantee.
- Audio uses the phone's installed offline English speech voice. This feed contains no paid API integration or audio files.
- No accounts, ledger, PIN, saved word cards, credentials or app source code are published here. Word cards stay on the phone and may be included in its private local backups.
- AI-generated language-learning material can contain mistakes. News articles include sources and event dates. This is not a news wire or professional advice.
